# Subway Rush — Full-screen Runner Upgrade

## Changes
- Rebuilt the runner presentation with an immersive responsive stage and optional browser/WebView fullscreen mode.
- Added pause/resume, restart, score, distance, coin and speed HUDs.
- Added large touch controls alongside swipe gestures and keyboard controls.
- Added richer 3D obstacle models: subway train cars, cargo crates, overhead low-clearance barriers, multi-cone roadworks and solid lane blockers.
- Improved obstacle materials, coin detail, responsive camera sizing and mobile rendering settings.
- Preserved the existing player character/wardrobe integration, scoring, best-score storage, sound effects and capped phone-game reward flow.

## Controls
- Swipe left/right: change lanes.
- Swipe up or tap jump: jump.
- Swipe down or tap slide: slide under overhead barriers.
- Arrow keys / WASD: move; Space: jump; P or Escape: pause.
- Use the expand button for fullscreen.
