# Tactical Range — Battle Arena Upgrade

This update expands the existing Tactical Range into a battle-royale-inspired 3D combat arena while retaining the existing character rig, weapon system, enemy AI, wave progression, economy rewards and scene routing.

## Added
- Neon industrial arena dressing: illuminated pylons, overhead gantries, floor lane strips and cyan/magenta lighting.
- Deployable temporary Glow Wall skill. It creates a translucent energy barrier that blocks shots and can be used as tactical cover.
- Blink Dash skill with collision-aware movement and cooldown.
- Med Kit skill that restores up to 38 HP, capped at 100.
- Touch-friendly skill HUD with cooldowns and disabled states.
- Touch-friendly weapon selectors for the existing pistol and sniper weapons.
- Existing weapon firing, projectile tracers, muzzle flashes, hit markers, enemy waves and cover-aware combat remain active.

## Controls
- Existing third-person movement, aim and fire controls remain unchanged.
- Use the on-screen PISTOL / SNIPER buttons or keyboard 3 / 4 to select weapons.
- GLOW WALL deploys temporary forward cover.
- BLINK DASH moves the player forward if the destination is not blocked.
- MED KIT restores health when below full HP.

## Notes
This is a single-player combat arena upgrade. It does not claim Free Fire assets, multiplayer matchmaking, or server-backed battle royale functionality. The visuals and gameplay are original and inspired by the broad tactical-arena genre.
