# Phase 17 — Ten-page 3D comic

Added **The Last Ride to Campus**, a ten-page illustrated Everyday Comics story set around UNIPORT and Port Harcourt. Each page is rendered from low-poly 3D characters and page-specific environments, including the university gate, keke, danfo, rainy roadside shelter, food spot, petrol station, hotel lobby and campus return. Dialogue bubbles, page captions, reading progress, fixed-camera large-scene view, scene capture to Gallery and motion-comic playback use the existing comic system.

The story is fully local and uses the project's bundled Three.js. No remote image dependency or external video file is required.
