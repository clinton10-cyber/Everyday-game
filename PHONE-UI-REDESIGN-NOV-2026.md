# Phone UI Redesign — November 2026

## Changes
- Added immersive full-screen presentation for Bank, Social, Justice and Games phone apps.
- Subway Run now opens inside a full-screen game surface by default; its own pause/fullscreen controls remain available.
- Redesigned Garden City Connect with a photographic feed, player account card, account avatars, creator-style posts and clearer social controls.
- NPC social posts now use photographic city imagery when a live in-game screenshot is unavailable.
- Redesigned Everyday Pay with a cleaner green wallet dashboard, prominent balance card, shortcut actions and responsive banking layout inspired by familiar Nigerian fintech app patterns. It remains an in-game simulation and does not use OPay branding or connect to real OPay services.
- Added a photographic Justice hero and improved case-card hierarchy.

## Notes
- Game state and progress remain locally stored as before.
- Social feed photography uses remote Unsplash image URLs, so those photos require an internet connection; the game itself is not converted into an online game.
- No real payment integration was added in this UI pass.
